# Аудит и тесты

Детерминированные проверки измеряют границы и пересечения, вместимость текста, кегль и контраст, соответствие палитре, сохранность текстовых полей и данных. Не прошедший проверку вариант не считается готовым.

Контекстуальный аудит использует Qwen для проверки смысловых связей и соответствия исходному слайду. Замечания сохраняются с указанием затронутых объектов. Ответ модели не заменяет визуальную приёмку.

| Область | Тесты в `user-app/tests` |
| --- | --- |
| Импорт и ресурсы | `binary-*.test.ts`, `visual-package.test.ts`, `embedded-fonts.test.ts`, `source-*.test.ts` |
| Дизайн-система и компоненты | `catalog.test.ts`, `component-*.test.ts`, `editable-*.test.ts`, `reconstruction*.test.ts` |
| Содержание и вёрстка | `studio-*.test.ts`, `presentation-*.test.ts`, `text-fields.test.ts` |
| Модельные ответы и повторы | `qwen-*.test.ts`, `model-recovery.test.ts`, `provider-*.test.ts`, `routerai.test.ts` |
| История, отмена и фоновые задания | `workspace.test.ts`, `processing-jobs.test.ts`, `upload-cancellation.test.ts`, `studio-history.test.ts` |
| Экспорт | `pptx-package.test.ts`, `slides.test.ts`, сценарии `browser/` |
| Пользовательские сценарии | `browser/`: импорт, галерея, генерация, история, компоненты, экспорт |

Из `user-app`:

```bash
npm test
npm run typecheck
npm run build
npm run test:browser
```

Playwright запускает отдельный сервер на 5194 и отдельное хранилище без рабочих API-ключей. Часть сценариев с реальными файлами требует внешних fixtures и может быть пропущена. Диагностические скрипты в `scripts/` не входят в этот набор; некоторые обращаются к живому серверу или платной модели.

Проверка публикуемой копии 30 сентября 2026: установка, типизация и production-сборка прошли. В Node-наборе прошли 704 из 712 тестов. Семь падений — чтение `sourceCatalogId` при отсутствии аудита в `calibration` и `component-preparation`; одно — ожидание доступности worker в `recipe-discovery`. Полный браузерный набор в этой публикации не прогонялся.

Снимок проверен в отдельном хранилище: главная страница, банк стилей, проекты и их API возвращают HTTP 200. В публичный архив включены четыре дизайн-системы и четыре основных проекта, включая последний десятислайдовый запуск. Экспериментальные проекты MSP 2 не включены. Исходные PPTX проверены по контрольным суммам.

Зелёные тесты подтверждают проверенные свойства, но не гарантируют художественное качество, полную поддержку PowerPoint и скорость на неизвестном шаблоне. Полная матрица браузеров из ТЗ пока не проверена.
