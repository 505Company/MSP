# Модели

Основная модель — [Qwen3.8-27B](https://huggingface.co/Qwen/Qwen3.8-27B): открытые веса, лицензия Apache 2.0. Она используется для смыслового разбора шаблонов, группировки содержания, выбора компонентов и контекстуального аудита. Веса в репозиторий не входят.

| Подключение | Имя в API | Назначение |
| --- | --- | --- |
| Intelion | `qwen3.8-27b` | Анализ шаблонов и резервный маршрут генерации |
| RouterAI / DeepInfra | `qwen/qwen3.8-27b`, BF16 | Основной маршрут модельной генерации |
| RouterAI / AkashML | `qwen/qwen3.8-27b`, FP8 | Альтернативный маршрут генерации |

Настройки — `user-app/.env.example`, выбор маршрута — `user-app/lib/uploads/provider-failover.ts`. Для сохранённых запросов фиксируются провайдер, модель, параметры и ответ. Точную ревизию весов внешние API не закрепляют: `weightsRevision` остаётся `null`.

Для текущего запуска нужны Node.js, Chromium и доступ к API; GPU на компьютере пользователя не требуется. Самостоятельное развёртывание весов этим репозиторием не настроено. Требования к нему зависят от точности, контекста и сервера инференса; см. [официальные файлы и инструкции модели](https://huggingface.co/Qwen/Qwen3.8-27B/tree/main).

Быстрая вёрстка готовых рецептов, геометрические проверки и экспорт работают без LLM. Модель text-to-image в основной процесс не подключена. Обязательный для финального этапа маршрут через инфраструктуру VK нужно настроить отдельно; текущая цепочка провайдеров сама по себе это требование не подтверждает.
