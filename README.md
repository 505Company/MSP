# MSP

Сервис для создания презентаций в стиле загруженного шаблона. Из PPTX или PDF извлекаются цвета, шрифты, графика и композиции. Затем MSP собирает слайды из текста, проверяет вёрстку и экспортирует результат в HTML, PPTX и PDF.

Основное приложение — `user-app`. В нём находятся банк дизайн-систем, проекты, история генераций и три режима: быстрый, сбалансированный и творческий. `admin` — ранний интерфейс, `src` — отдельный профилировщик PPTX. MSP 2 — экспериментальная ветка, доступная по `/msp2`.

## Запуск

Нужны Node.js 22.13 или новее и npm. Модель работает через API; локальная видеокарта не нужна.

```bash
git clone https://github.com/505Company/MSP.git
cd MSP/user-app
npm run install:ci
npx playwright install chromium
cp .env.example .env.local
npm run dev
```

Приложение откроется на `http://localhost:5173`. Фоновый обработчик запускается вместе с сервером. Для генерации и импорта компьютер и сервер должны оставаться включёнными.

В `.env.local` задайте `INTELION_API_KEY` для анализа шаблонов и `ROUTERAI_API_KEY` для модельных режимов генерации. Адреса и имена моделей уже есть в `.env.example`. Генератор также поддерживает резервный маршрут Intelion. Ключи остаются на сервере. Просмотр сохранённых результатов не требует новых запросов к модели.

## Дизайн-системы и проекты

Снимок данных находится в [Releases](https://github.com/505Company/MSP/releases/tag/snapshot-2026-09-29): четыре дизайн-системы и четыре проекта — VK Workspace, VK Education, VK Tech и «Горбунов_Коллаж». Внутри — исходники, библиотеки, шрифты и сохранённые результаты, включая последний запуск. Состав — в [data/catalog.json](data/catalog.json).

Скачайте `msp-data-2026-09-29.tar.gz` и перед первым запуском восстановите данные из корня репозитория. Нужен Python 3:

```bash
python3 scripts/restore-data.py /путь/к/msp-data-2026-09-29.tar.gz
```

Скрипт проверяет контрольные суммы и отказывается перезаписывать существующее хранилище. Секретов и очередей фоновых заданий в архиве нет.

## Проверки и ограничения

В `user-app`: `npm test`, `npm run typecheck`, `npm run build`; браузерные проверки — `npm run test:browser`.

Это рабочий прототип. Сложные эффекты, нестандартные шрифты и плотные слайды требуют визуальной проверки. Экспорт сохраняет редактируемые объекты там, где они поддержаны; исходные растровые изображения остаются изображениями. Время полного запуска зависит от шаблона и API: лимит в пять минут для любого входа пока не подтверждён. Проверка всех браузеров из ТЗ не завершена.
